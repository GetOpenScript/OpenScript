# OpenScript Icon Assets

- `OpenScript_v1.png`: Original monochrome terminal prompt (`> _`) concept.
- `OpenScript_v2.png`: Ocean wave terminal monogram (`>_ O`) master logo introduced for Chrome Web Store release.
- `OpenScript_v3.png`: Transparent-background version of the v2 logo; current master for extension icons.
- `icon-{16,32,48,128}.png`: Production extension icons generated from v3 master via `npm run build:icons`.
